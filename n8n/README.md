# העוזרת האישית של רוני — בוואטסאפ

מערכת שרצה על השרת הקיים (Hetzner) ב-n8n. **אפס עלות נוספת.**

## מה יש כאן

| קובץ | מה זה עושה |
|---|---|
| `01-brain-whatsapp.json` | המוח. מקבל כל הודעה בוואטסאפ ומחליט מה לעשות |
| `02-morning-reminder.json` | תזכורת בוקר אוטומטית, ראשון–חמישי ב-7:00 |

## מה המוח יודע לעשות

רוני שולחת הודעה חופשית בוואטסאפ — בלי פורמט, בלי פקודות:

- **טקסט** → מבין את הכוונה ומפעיל כלי: יומן, מייל, מסמכים, גיליונות
- **תמונה של מבחן** → בודק, מנתח טעויות, מציע ציון ומחזיר בוואטסאפ
- **הקלטה קולית** → מתמלל ומחזיר סיכום פגישה מובנה

## מה עוד לא מחובר (מותקן בשלב ההתקנה)

מזהי החיבורים בקבצים הם מצייני מקום — הם מוחלפים בהתקנה:

| מציין מקום | מה מחליף אותו |
|---|---|
| `WA_CRED`, `WA_TRIGGER_CRED`, `WA_PHONE_ID` | חיבור וואטסאפ של מטא |
| `GEMINI_CRED` | מפתח Gemini (חינם) |
| `GCAL_CRED`, `GMAIL_CRED`, `GDOCS_CRED` | חיבור Google של רוני |
| `RONI_PHONE` | מספר הוואטסאפ של רוני |
