# 🧠 אני מבינה פונקציות!

אפליקציית לימוד אינטראקטיבית בעברית, בקובץ HTML עצמאי אחד (בלי צורך בהתקנה או שרת), שמלמדת את מושג **הפונקציה** מהיסוד ועד לרמת תרגילי בגרות של פרבולה וישר (חיתוך, שטחים).

## למי זה מיועד

לומדת שמתחילה **ממש מאפס** במושג הפונקציה, עם קשיי קשב וריכוז - לכן האפליקציה בנויה מראש כך ש:

- **אין שעון עצר ואין תחרות** - קצב אישי לגמרי, בהשראת הגישה הפינית ללמידה רגועה ונטולת לחץ.
- **מושג אחד בכל פעם, בצעדים קטנים** - מהקונקרטי למופשט (בהשראת שיטת סינגפור: קודם התנסות, אחר כך שם למושג).
- **הצלחה מובטחת, לא כישלון** - כל תשובה שגויה מקבלת הסבר ממוקד ואפשרות לנסות שוב, בלי "עונש".
- **בונה חשיבה, לא רק תשובות** - בכל שלב תרגול יש תיבת "איך חושבים על זה?" עם תהליך חשיבה מודרך.
- **הוראה מתקנת** - מתחילים מהיסוד המוחלט (מהי בכלל פונקציה) ובונים כל שלב על הקודם, בלי לדלג.

## מבנה המסע (7 שלבים)

0. מה זו בכלל פונקציה - מכונת קלט/פלט, מבחן הקו האנכי
1. שפת הפונקציות f(x)
2. מציירים וקוראים גרף
3. הקו הישר - שיפוע וחיתוך עם ציר y
4. הפרבולה - קודקוד, ציר סימטריה, שורשים
5. תחומי עלייה/ירידה וחיוביות/שלילות
6. שיא המסע: מציאת נקודות חיתוך בין ישר לפרבולה, וחיבור לשאלות שטח בסגנון הבגרות

כל שלב כולל: סיפור מסגרת, גרף אינטראקטיבי עם מחוונים, הגדרת המושג, תרגול עם משוב מיידי ומילון מושגים מתמלא לאורך הדרך. ההתקדמות נשמרת אוטומטית בדפדפן (אין צורך בהתחברות).

## הרצה

פשוט פותחים את הקובץ `index.html` בדפדפן - אין build, אין שרת, אין תלויות חיצוניות.

### שיתוף עם טלפון (Android, בלי כרום, בלי וואטסאפ)

וואטסאפ חוסם שליחת קבצי HTML ישירות, אז כדי להעביר את האפליקציה לטלפון:

1. מעלים את `index.html` ל-Google Drive.
2. לוחצים קליק ימני על הקובץ ← "שיתוף" ← משנים ל"כל מי שיש לו את הקישור".
3. מעתיקים את הקישור ושולחים אותו (בוואטסאפ אפשר לשלוח קישור, גם אם לא קובץ).
4. בטלפון, פתיחת הקישור לפעמים תוריד את הקובץ במקום להציג אותו - אם זה קורה, כדאי לחפש באפליקציית Drive אפשרות "פתיחה בתצוגה מקדימה" במקום הורדה.
