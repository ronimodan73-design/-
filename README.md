# קניה חכמה - השוואת מחירים

אפליקציית ווב (PWA) בעברית שעוזרת לקנות בחוכמה מ-AliExpress, Shein ו-Temu:

- **השוואת מחירים, איכות ודירוגים** - הקלידו שם מוצר, והאפליקציה מחפשת מידע עדכני ברשת ומשווה בין שלוש הפלטפורמות (מחיר, דירוג, ביקורות, יתרונות/חסרונות).
- **המלצה חכמה** - איזו פלטפורמה הכי משתלמת עבור המוצר, ומתי כדאי לקנות (עכשיו או לחכות למבצע).
- **המרת מידות** - טבלאות המרה בין מידות ישראל/אירופה, ארה"ב, בריטניה ואסיה, לביגוד נשים/גברים/ילדים ולנעליים.
- **לוח מבצעים** - תאריכי המבצעים הגדולים בפלטפורמות הסיניות.
- **שמירת השוואות** - שמירת חיפושים קודמים באחסון מקומי בדפדפן, לצפייה חוזרת ללא חיפוש נוסף.
- **יועץ כלכלי אישי** - מעקב אחרי הכנסות והוצאות, סיכום חודשי ויומי, רשימת קניות ותזכורות אישיות, ויועצת כלכלית מבוססת AI שעונה על שאלות כספיות בשפה פשוטה מאוד (ללא מונחים כלכליים), עם הסבר מה הרווח, מה ההפסד, ועצה מעשית.
- **Model Router** - שכבת ניהול שלא תלויה בספק AI יחיד. כל בקשה מנסה קודם את Codex (OpenAI), ואם הוא לא זמין או שהמכסה שלו הסתיימה - עוברת אוטומטית ל-Kimi K2 (Moonshot), ואם גם הוא לא זמין - ל-Gemini כרשת ביטחון אחרונה.

## הרצה מקומית

**דרישות מקדימות:** Node.js

1. התקנת תלויות:
   `npm install`
2. הגדרת מפתחות API בקובץ [.env.local](.env.local) - ראו "Model Router" למטה
3. הרצת האפליקציה:
   `npm run dev`

## Model Router

כל קריאה ל-AI (השוואת מוצרים ויועצת כלכלית) עוברת דרך `services/modelRouter.ts`, שמנסה ספקים לפי הסדר הבא ועובר אוטומטית לספק הבא אם הנוכחי לא מוגדר, לא זמין, או שהמכסה שלו הסתיימה:

1. **Codex (OpenAI)** - `OPENAI_API_KEY` (אופציונלי: `CODEX_MODEL`, ברירת מחדל `gpt-5-codex`; `OPENAI_BASE_URL`)
2. **Kimi K2 (Moonshot)** - `MOONSHOT_API_KEY` (אופציונלי: `KIMI_MODEL`, ברירת מחדל `kimi-k2-0711-preview`; `MOONSHOT_BASE_URL`)
3. **Gemini (Google)** - `GEMINIAPIKEY` (אופציונלי: `GEMINI_MODEL`, ברירת מחדל `gemini-flash-latest`)

מספיק להגדיר מפתח אחד כדי שהאפליקציה תעבוד. אם מוגדרים כמה מפתחות, הראוטר תמיד ינסה קודם את הראשון ברשימה, ויחשוף בתשובה איזה ספק בפועל ענה (מוצג באפליקציה עם 🤖).
