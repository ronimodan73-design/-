# QA — לפני מסירה

שני חצאים. אחד רץ, אחד נקרא. שניהם חובה.

## החצי המכני — `qa.py`

```bash
python3 $SKILL/scripts/qa.py out/<שם>.pptx --anim          # --strict = אזהרה נחשבת כישלון
```

| בדיקה | נכשל על |
|---|---|
| bidi | עברית שמעורבת בספרות/לטינית בלי `pmx()` — הבאג ששולח `24 : 6 + 5 × 3` הפוך |
| bounds | אובייקט שחורג מגבולות השקופית — טקסט חתוך אצל מורה אחרת |
| density | מעל 320 תווים בשקופית |
| legible | טקסט מתחת ל-12pt |
| fonts | כל פונט שאינו מותקן בכל מחשב בבית הספר |
| notes | שקופית בלי Teacher Action / Student Thinking (אזהרה) |
| anim | שקופית תוכן בלי שלבי חשיפה (אזהרה, עם `--anim`) |
| weight | קובץ כבד, תמונה לא דחוסה, asset שאינו בשימוש |

בנוסף, תמיד:
```bash
python3 ~/.claude/skills/synced/pptx/scripts/office/validate.py out/<שם>.pptx
```

## החצי הפדגוגי — קריאה, שקופית-שקופית

### הרעיון
- [ ] האם הרעיון **נבנה** בהדרגה, או הוכרז?
- [ ] האם משהו נחשף מוקדם מדי? (השאלה החשובה ביותר ברשימה)
- [ ] האם הנוסחה מופיעה רק אחרי שהרעיון הובן?
- [ ] האם הפתרון מופיע שלב-שלב, עם נימוק לכל שלב?
- [ ] האם תשובה כלשהי יושבת על אותה שקופית עם השאלה שלה?

### האיורים והאנימציה
- [ ] האם יש איורים מתמטיים אמיתיים, ולא קישוט?
- [ ] האם כל איור מדויק — נקודות על הרשת, חיתוכים במקום הנכון?
- [ ] האם כל אנימציה עונה על "מה התלמיד מבין עכשיו?"
- [ ] האם כל האיורים מיושרים ובאותה שפה חזותית?
- [ ] האם מושג שקיבל צבע שומר עליו לאורך כל המצגת?

### ההוראה
- [ ] האם קיימת הוראה מתקנת בתוך המצגת, ולא רק בהערות?
- [ ] האם יש טעות נפוצה **ותיקון שלה**?
- [ ] האם התלמיד מקבל הזדמנות לזהות את הטעות בעצמו?
- [ ] האם קיימות כמה רמות חשיבה — לא רק תרגילים טכניים?
- [ ] האם יש שאלת אוריינות?
- [ ] האם לכל שקופית יש תפקיד פדגוגי ברור? אם לא — למחוק.

### המסך
- [ ] האם הטקסט גדול מספיק לשורה האחורית?
- [ ] האם יש שקופית עמוסה? (עדיף שלוש פשוטות)
- [ ] מוקד חזותי אחד בכל רגע?
- [ ] אין טקסט חתוך, אין חפיפה?
- [ ] RTL תקין — וכל נוסחה בכיוון המתמטי הנכון?

### הקבצים
- [ ] PPTX נפתח תקין ואפשר לערוך אותו?
- [ ] האנימציות רצות בסדר הנכון, לחיצה-לחיצה?
- [ ] MP4 משמר את רצף ההוראה ואת קצב החשיפה?
- [ ] PDF נראה תקין ומודפס נכון?
- [ ] שלושת הקבצים באותו שם, וקלים לשליחה בוואטסאפ?

## בדיקה ויזואלית — לא לוותר עליה

לא שולחים דק שלא ראינו בעיניים:

```bash
python3 $SKILL/scripts/render.py out/<שם>__build.pptx --pdf out/<שם>.pdf \
        --mp4 out/<שם>.mp4 --timing out/<שם>__timing.json --keep-frames frames
```

ואז מסתכלים על הפריימים — לפחות: שער, שקופית בניית הרעיון, שקופית הנוסחה,
שקופית הטעות. בודקים כיוון של ביטוי מתמטי אחד לפחות מול מה שהתכוונת.

**סעיף שנכשל — מתקנים לפני המסירה.** לא שולחים "כמעט".
